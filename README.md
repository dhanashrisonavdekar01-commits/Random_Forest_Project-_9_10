## 📌 Project 2: Fraud Check Prediction

### Objective
Predict whether a person is Risky or Good based on taxable income.

### Business Rule
- Taxable Income <= 30000 → Risky
- Taxable Income > 30000 → Good

### Steps Followed
- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Building using Random Forest
- Model Evaluation

### Model Accuracy
≈ 76%

### Insights
- Income plays a major role in classification.
- Balanced class weight improved predictions.
- Random Forest handled feature importance effectively.
